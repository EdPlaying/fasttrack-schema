<h1 align=center>FastTrack Schema</h1>

<p>La tecnología fue hecha para simplificar tareas, en una empresa de mensajería de última milla esta base de datos fue estructurada para la trazabilidad de envíos, seguimiento estado de pagos, control de pagos.</p>


<h2>Estrategias ⚡</h2>
<ul>
  <li><b>Normalización: </b><p> Estructurado siguiendo los principios NF3 para asegurar la integridad referencial y evitar redundancias.</p></li>
  <li><b>Business Intelligence: </b><p>Tablas con información adicional al funcionamiento diseñadas con el propósito de identificación de áreas de mejora.</p></li>
  <li><b>Seguridad y Control de Acceso (RBAC): </b><p>En pro de tener la información segura y confiable se controlan los accesos de los usuarios respecto a sus funciones.</p></li>
  <li><b>Auditoría Interna: </b><p>Mediante el seguimiento de fechas, horas y actores se puede hacer el rastreo e identificación de eslabones frágiles en la estructura.</p></li>
</ul>

<h2>Tecnologías 🛠️</h2>
<ul>
  <li><b>Motor de base de datos: </b><p>MySQL</p></li>
  <li><b>Herramientas de modelado: </b><p>MySQL Workbench</p></li>
</ul>
